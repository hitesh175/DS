# Data Science Learning Notebooks

A collection of notebooks from data science coursework, covering tools and introductory financial-data exploration.

## Notebook guide

| Notebook | Focus |
| --- | --- |
| [DataScienceTools.ipynb](DataScienceTools.ipynb) | Data science tools exercise |

## Explore locally

Install Python and Jupyter, clone this repository, and launch:

```bash
python -m pip install jupyter
jupyter notebook
```

Open a notebook and review its import and installation cells before running it from top to bottom. A consolidated dependency file is not currently provided.

## Reproducibility

Saved outputs reflect the original coursework run. External data sources may change or require network access, so a fresh execution may produce different results. These notebooks document learning exercises and historical analysis.
